# Marketplace

The marketplace displays published business profiles and supports search, filters, profile pages, and portfolio browsing. A listing can be connected to an authenticated business account through an administrator-reviewed claim.

Public profile content is intentionally different from private wedding documents. The current media route serves vendor-profile images that have explicit public visibility. Do not reuse it for contracts, invoices, or other private wedding documents.

Search and directory lists must use the shared pagination contract and stable ordering. See [API conventions](../api/API_CONVENTIONS.md).
