# Feature status

## Working now

- English and French preference with persisted switching
- Cardo display typography and Nunito interface typography
- Light, dark and system themes
- Registration and login through preview or API mode
- Guest search, RSVP filtering, creation, editing and removal
- Task search, status filters, creation, editing, completion and removal
- Budget category creation, editing, removal and recalculated totals
- Vendor search, saving, creation, editing and removal
- Calendar month navigation and event creation, editing and removal
- Seating table creation, arrangement, capacity calculation and removal
- Menu editing
- Document search, metadata creation, local file selection, editing and removal
- Booking search, creation, lifecycle editing and removal
- Payment creation, editing, removal and CSV export
- Conversation search, selection, read state and message sending
- Note search, creation, editing and removal
- Responsive reports and marketplace portfolios
- Profile settings, language settings and preference toggles

Preview changes persist in the browser. API mode persists wedding-module records through the current .NET backend.

## Production integrations still required

- Email and phone verification
- Password reset and social sign-in providers
- Couple/planner wedding membership and ownership workflows
- Real document object storage and malware scanning
- Email, SMS and push delivery
- Live payment-provider settlement verification
- Real-time messaging transport
- Calendar-provider synchronisation
- Subscription billing and platform moderation operations
- End-to-end browser testing against a deployed environment

These integrations require provider accounts, secrets and production policy decisions. The interface is ready for them, but local UI behavior is not evidence that an external provider has been configured.
