# Roadmap

This is a direction, not a release commitment. Production capabilities require product decisions, service configuration, migrations, and verification before they are advertised as available.

## Near term

- Keep account, wedding ownership, and collaborator permissions covered by repeatable tests.
- Maintain one documented pagination contract across list APIs.
- Close English/French gaps for fixed UI labels and errors.
- Run the staging browser suite against a dedicated test deployment and test account.
- Improve usability of administrative claim review and script environment selection.

## Later

- Introduce organisation and membership records for venues and larger businesses.
- Add staff roles and permission grants without hard-coding job titles into access checks.
- Add capability-based subscription entitlements and billing integration.
- Define private document access, retention, and media operations before choosing production infrastructure.

The media storage/scanning project is explicitly deferred; it is not a prerequisite to the work currently implemented.
